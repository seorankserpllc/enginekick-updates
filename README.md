# EngineKick OS releases

Signed release files for the EngineKick OS WordPress plugin. Sites with this address as their update source install new versions automatically after verifying the Ed25519 signature in update.json and each package's SHA-256.

Update source address: https://raw.githubusercontent.com/seorankserpllc/enginekick-updates/main/update.json

This repository holds release files only, not the source code.
